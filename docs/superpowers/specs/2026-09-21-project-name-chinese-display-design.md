# 运动项目中文展示设计

## 目标

所有浏览器端面向用户展示的运动项目名称统一显示中文，例如 `ROWING` 显示为“赛艇”、`CANOE_SPRINT` 显示为“皮划艇”。

## 边界

- 数据库、接口参数、权限范围、筛选状态和表单提交继续使用项目代码。
- 仅修改 React 页面与组件的可见文本；不修改服务端查询、导入匹配或训练数据口径。
- 统一复用 `shared/projects.ts` 中已有的 `projectLabel(project)`；历史中文值与未知值由该函数原样回退。
- 下拉框的 `<option value>` 继续提交代码，选项文本显示 `projectLabel(code)`。

## 验收

- 所有项目筛选、卡片、列表、标题、运动员与队伍关联信息均显示中文项目名。
- 不出现 `ROWING`、`CANOE_SPRINT` 等项目代码作为用户可见项目名称。
- 项目筛选、权限范围和请求参数保持代码值，功能不受影响。
- TypeScript 检查、受影响单元测试和生产构建通过。
