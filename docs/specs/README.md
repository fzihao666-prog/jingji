# 功能规格索引

本目录按可独立开发、验收和演进的功能边界组织规格；跨模块的架构约束见 `../architecture.md`。

| 规格 | 覆盖范围 |
| --- | --- |
| `authentication-and-access.md` | 登录注册、会话、账号、组织范围与审计 |
| `athlete-profile.md` | 运动员主数据、档案、体测与身体测量 |
| `training-sessions-and-load.md` | 专项训练场次、恢复状态与训练负荷 |
| `strength-training-plans.md` | 四周力量处方、执行结果与计划导出 |
| `training-data-import.md` | 体能结果和通用训练数据的导入、校验、提交 |
| `special-tests-and-performance.md` | 专项测试事件、成绩与竞技状态 |
| `health-and-recovery.md` | 伤病、疼痛、训练限制、康复与复查 |
| `overview-and-analysis.md` | 总览聚合、训练分析、个人与团队看板 |
| `ai-training-advice.md` | AI训练草案、人工确认与结果导出 |
| `device-connection.md` | 蓝牙设备连接及正式数据接入边界 |
