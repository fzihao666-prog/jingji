# 竞迹项目使用培训｜教练与领导会议讲解稿

适用对象：公司员工、教练、队伍负责人及领导。  
建议时长：40分钟讲解与演示，另留5～10分钟答疑。  
主线：数据从哪里来 → 如何导入 → 导入后怎么看 → 如何用于训练管理和汇报。  
本稿按当前项目功能和实际页面整理；按钮以会前已部署的版本为准。

> 使用方法：“照着讲”可以直接朗读；“屏幕操作”是你现场要做的动作，不用念。首次会议只需把一个队伍、一次基础体能测试的导入演示讲透，不必展示所有菜单。

## 一、讲解大纲与时间分配

| 环节 | 时长 | 屏幕展示 | 听众需要明白什么 |
| --- | --- | --- | --- |
| 1. 开场，说明今天学什么 | 2分钟 | 训练总览 | 今天重点学会把数据正确导进来 |
| 2. 项目有什么价值 | 4分钟 | 总览、个人档案 | 同一份数据服务记录、分析、管理和汇报 |
| 3. 系统从哪里开始使用 | 5分钟 | 项目/队伍/日期筛选、主要菜单 | 先选范围，再看数据；日常填报和批量导入各有用途 |
| 4. 数据导入完整演示 | 19分钟 | 数据导入、Excel、结果页面 | 选模板、填写、上传、人员确认、校对、入库和核对 |
| 5. 数据导入后怎么用 | 5分钟 | 体能测试、个人档案、训练总览 | 不同数据进入相应页面，不是导入后所有图表都会有变化 |
| 6. 周总结如何生成 | 3分钟 | 数据管理的报告页、Word | 选队伍和周次下载，修改在Word/WPS完成 |

## 二、会前准备：让演示顺利完成

1. **确认演示环境已更新到单表模板版本。** 下载“统一数据模板”，检查只有“运动员基础体能测试”一张工作表、16列。会前完成这一步，避免现场下载到旧版本。
2. 使用已有授权的教练或管理账号，提前登录，确定要展示的项目和队伍；不同账号可见范围可能不同。
3. 优先使用测试环境和演示队伍。文中示例数值都是教学示例，不是正式实测成绩；正式环境演示只能使用经确认的实际数据，不能为了图表好看编造数值。
4. 准备三份材料：从系统下载的原始名单模板、已经填好少量成绩的文件、已经成功导入并可查看的示例批次。没有测试环境时，准备已有真实批次，不现场提交虚构数据。
5. 用下载名单中的两名已有运动员准备演示，不改编号、姓名或队伍；保留第三名运动员身份信息，但不填成绩，用来解释空行会被忽略。
6. 电脑提前装好Excel或WPS，关闭无关窗口和通知。准备一份已生成的Word周总结，现场生成较慢时可直接打开讲解。
7. 选定导入后要查看的真实测试日期；查看图表时使用包含该日期的范围。不要把模板预填的当天日期误当成历史测试日期。

保留下载模板的全部16列，下面只展示需要回填的几列。日期统一填写本次实际测试日期。

| 已有运动员丙 | 留空 | 留空 | 留空 | 留空 | 留空 | 留空 |

**注意：表中“留空”是讲解说明，Excel实际单元格要真正为空，不填“留空”两个字。引体向上0表示实际进行了测试，有效完成次数确实为0。**

这三行足够演示：部分指标可填、未测留空、真实0保留、合理负值可填、只有名单的行不产生业务记录。

## 三、正式讲解流程与逐段讲稿

### 第1段｜开场：今天只要求大家记住一条主线（2分钟）

**屏幕操作：** 打开训练总览，选择演示项目与队伍，暂时不要逐个解释图表。

**照着讲：**

各位教练、各位领导，今天主要介绍竞迹怎么用于我们实际的训练工作。

我不准备按菜单从头念到尾，而是用一次完整的工作流程来讲：我们手里已经有运动员名单、测试成绩和训练记录，如何把这些数据放进系统，放进去以后能在哪里看，又能为教练和管理工作提供什么帮助。

今天最重要的是数据导入。大家会后不一定要马上掌握所有分析功能，但希望能完成三件事：知道该下载哪个模板，能把实际测得的数据填对，能确认这些数据已经导入到正确的运动员和日期下。

我们按照“准备数据、导入系统、查看结果、形成总结”这条线走一遍。

**转场：** 在实际操作前，先用几分钟说明我们为什么要做这件事。

### 第2段｜项目的价值：让数据积累下来，并且用得起来（4分钟）

**屏幕操作：** 展示训练总览，再打开一名有真实历史记录的运动员档案。

**照着讲：**

过去，名单、体测成绩、训练日志和周总结往往分别在不同的Excel、文件夹或教练记录中。单次找到一个成绩并不难，但要连续比较一个运动员几个月的变化，或者汇总一支队伍一周的训练情况，就需要重新找表、对人、核对日期，再整理成报告。

竞迹的作用，是把这些记录按运动员、队伍和时间关联起来，让同一份已经确认的数据能够持续使用。

对教练来说，主要有三个用途。第一，把日常训练和测试记录积累下来，减少每次重新找资料的工作；第二，查看运动员个人变化，并结合队伍情况作参照；第三，整理周总结时，有现成的数据和图表作为基础。

对领导和队伍负责人来说，重点是看到一段时间内训练投入和节奏如何、哪些信息已经记录、哪些情况值得进一步了解，以及教练接下来准备怎么调整。汇报可以围绕同一份数据展开，便于追踪。

这里也要说明，系统能做什么取决于我们记录了什么。只导入一次体测成绩，就先积累一次测试记录；要看训练量、训练负荷和恢复变化，还需要持续记录课次和恢复数据。空白图表表示相关数据还没有形成，不能理解成训练没有开展，也不能用0补齐。

**这一段最后一句：** 数据要先记录真实、关联正确，再逐步谈比较和分析。

### 第3段｜先认识使用入口，不用记住所有功能（5分钟）

**屏幕操作：** 指出项目、队伍、日期筛选；展示主要菜单。只打开必要页面，不展开全部功能。

**照着讲：**

进入系统后，先看三个范围：现在选的是哪个运动项目、哪支队伍、哪段日期。这三个范围不对，即使系统里有数据，也可能看不到想看的结果。

日常使用可以先记住这几个入口。

| 入口 | 适合做什么 | 现场讲解重点 |
| --- | --- | --- |
| 训练总览 | 看选定时间内队伍的整体训练情况 | 先看范围，再看投入和节奏 |
| 运动员管理、运动员档案 | 查名单、查个人历史与变化 | 数据最终要归到具体运动员 |
| 体能训练、专项训练 | 看相应训练和测试数据 | 体能测试、专项成绩、日常训练不是同一种记录 |
| 数据管理 → 数据导入 | 批量导入已有Excel数据 | 今天重点演示的入口 |
| 数据管理 → 报告 | 生成队伍训练周总结Word | 下载后可以继续修改 |

记录数据主要有两种方式。已有Excel成绩或需要集中录入一批数据，就使用导入；日常现场记录也可以通过已有录入入口或微信小程序完成，具体由队伍选择合适方式。

对教练来说，不需要每天把所有页面都点一遍。可以围绕“记录、核对、看变化、做总结”来用。对领导来说，主要看已经确认的数据、队伍趋势和周期总结，理解统计范围和数据覆盖情况。

**转场：** 接下来用最常见的一次身体和基础体能测试，完整演示如何导入。

### 第4段｜数据导入：从下载到确认入库（19分钟）

#### 4.1 先选对模板（2分钟）

**屏幕操作：** 进入“数据管理 → 数据导入”，指出“模板预填队伍”和四个模板按钮。

**照着讲：**

这里有几种模板，并不是每次都要全部填写。按你手里的数据选一种就可以。

| 手里有什么数据 | 使用哪个模板 |
| --- | --- |
| 身高、体重、五项实测最大力量、引体向上、CMJ、平板支撑、坐位体前屈 | **统一数据模板**：今天主要演示，只有一张表 |
| 需要集中建立运动员档案或补充资料 | 队员资料模板 |
| 日常训练课次、力量训练组次、恢复记录 | 训练记录模板 |
| 统一单表没有覆盖的专项或其他体能测试 | 测试成绩模板，按实际项目及模板要求填写 |

注意，“统一数据模板”现在是为了常见基础体能测试做的简洁表，它不包含全部日常训练和所有专项成绩。

旁边的“导出统一数据”是把系统里已有的数据导出来，和下载一份等待填写的新模板是两件事。今天新增测试数据，我们点击“统一数据模板”。

#### 4.2 选择队伍，下载已经有名单的表（2分钟）

**屏幕操作：** 在“模板预填队伍”中选演示队伍，点击“统一数据模板”，打开下载文件。

**照着讲：**

先确认项目，再选择这次准备填数据的队伍。这里只能看到账号有权限访问的范围。

下载以后，已有运动员的编号、姓名、所属队伍已经填好，测试日期默认当天。历史测试一定改成实际测试日期。

这张表只有一张工作表，名字叫“运动员基础体能测试”。第一行是字段名称和单位，第二行开始填成绩；表头和前三列已经冻结，向右填写时仍能看到人员身份。

**强调：** 已有人员不用重新编号，不改系统预填编号，不拿其他运动员的一行直接改姓名来代替。

#### 4.3 填写规则：把这六点讲清楚（5分钟）

**屏幕操作：** 展示表头的五组字段，再打开会前准备好的回填文件。

**照着讲：**

这16列可以分为五组：基本信息、身体指标、最大力量、基础体能和备注。大家不用每次都填满，只填写这次实际测到的项目。

第一，**一名运动员一次测试占一行**。同一个人不同日期的测试可以另起一行，编号保持一致，测试日期写各自实际日期。

第二，**编号、姓名和队伍是用来认人的**。已有人员保留预填内容。新运动员在新行填写真实姓名和系统已有队伍名称，编号留空，上传后沿用人员确认流程，不要求为了这次测试先补齐生日、性别，也不使用身份证号来匹配。

第三，**日期写实际测试日期**，如“2026-11-02”。模板默认当天只是为了方便，不能把几个月前的测试全部导成今天。

第四，**数值只填数字，单位看表头**。例如体重填75，不填“75kg”；平板支撑按秒填写，例如90秒就填90，不填“1分30秒”。引体向上填写有效完成的整数次数，坐位体前屈可以填写合理负值。

第五，**五项最大力量指实测1RM**，包括卧推、卧拉、深蹲、硬拉、高翻。日常训练中做了60公斤、每组8次，这不是实测1RM，不能直接放进最大力量列。日常重量、次数、组数使用训练记录对应模板。

第六，**没测试的项目真正留空，实际测到0才填0**。不填横线、“未测试”或其他占位文字。这里甲运动员的引体向上0，表示测试确实做了，有效次数是0；CMJ留空，表示这次没有记录这个成绩。这两种情况含义完全不同。

再看丙运动员，这一行只有名单和日期，没有任何身体测量或测试成绩。上传时系统会忽略这行，不会为他生成一条空成绩，所以大家不需要先把名单里未参测的人全部删除。

**可以问现场一句：** “没有做卧推测试，这一格填0还是留空？”停顿后回答：“留空。只有真实测试结果为0时才填0。”

#### 4.4 上传并检查：上传成功不等于已经入库（2分钟）

**屏幕操作：** 保存Excel，回到数据导入页，点击“选择Excel文件”，再点击“上传并检查”。

**照着讲：**

填完后保存Excel，在这里选择文件，再点“上传并检查”。系统会先识别人员和数据，检查日期、数值、单位以及记录是否重复。

这里要记住：**上传并检查只是预览和校对，还没有正式入库。** 我们需要看完人员和数据，再确认导入。

如果整个文件的记录日期都缺失，但确实属于同一个测试日期，可以在“缺失日期时使用”里明确选择统一日期。表里已有日期优先；像2月30日这样的非法日期，需要修正，不能靠默认日期掩盖。

#### 4.5 确认运动员：保证成绩跟对人（2分钟）

**屏幕操作：** 说明已有编号准确匹配时此步自动通过；如需展示新人确认，使用会前准备的测试批次，不临时创建正式人员。

**照着讲：**

已有运动员通过预填编号准确匹配时，这一步通常会自动通过，不需要大家一个个重新确认。

如果出现新运动员、同名人员，或者编号与姓名对不上，系统会让我们确认。这个时候要先确定是关联已有运动员，还是确实需要新建，不能为了尽快通过就随便选一个人。

新运动员先核对姓名和所属队伍，按页面完成确认即可。人员确认保存的是这次导入的对应关系，正式写入仍在最后确认导入时进行。

#### 4.6 校对并确认导入：重点看人、日期、值和更新（4分钟）

**屏幕操作：** 展示校对页的一条记录、异常筛选和最终确认信息，再提交准备好的合法示例。

**照着讲：**

来到校对页，不要求大家把正常记录重复点一遍。重点检查四件事：人对不对，日期对不对，数值和单位对不对，这次是新增还是更新已有数据。

如果出现错误，按页面指出的位置修正；需要回Excel批量处理时，可以下载问题清单，修正后重新上传。确实不准备导入的记录，可以明确排除。不要通过填0来消除错误。

同一份文件里，同一个人、同一天、同一项目出现不同成绩，需要按现有冲突处理流程选择，不能当成两条不同成绩直接忽略。系统已有数据与本次填写不同的，则要关注页面显示的更新内容：**最终确认可能更新已有记录，不能把它理解成只会追加。**

空白字段不会拿去清空原来的值；但如果你明确填了新的有效数值，包括真实0，确认后就按最终校对内容保存。

这里还有一个常见疑问：Excel只填了两名运动员，为什么系统识别出了多条记录？因为一行中既有身高体重，也有卧推、引体向上等成绩，系统会分别保存为身体测量和各项测试。**业务记录条数不等于运动员人数，也不等于Excel行数。**

校对没有问题，再确认导入。最后看导入结果里的新增、更新、无变化和排除等数量，而不是看到文件上传成功就退出。

#### 4.7 入库后核对一次（2分钟）

**屏幕操作：** 进入体能测试或相应测试记录，选正确项目、队伍及测试日期，查看刚导入的成绩；再到个人档案核对身体测量。

**照着讲：**

最后我们离开导入页，回到实际业务页面核对一次：这名运动员、这个日期、这项成绩是不是正确，身高体重有没有进入对应的身体测量记录。

这样，“下载、填写、上传、确认人员、校对入库、查看结果”才完整走完。以后有问题，也可以回到“最近导入批次”查看这次处理结果。

### 第5段｜导入后的数据怎么用（5分钟）

**屏幕操作：** 依次展示体能测试、运动员档案、训练总览；每页只解释一个问题。

**照着讲：**

导入不是终点，接下来把数据用于三个问题。

第一个问题，**运动员的测试表现有没有变化？** 在体能测试里选指标和日期，看对应成绩及已有趋势。同一协议、同一单位的记录才适合直接比较。只有一次测试时，我们得到的是起点，还不能说明长期趋势。

第二个问题，**这个人的状态放到个人历史和队伍里怎么理解？** 在运动员档案中，查看已有的身体测量、体能和专项测试，以及训练和恢复记录。先观察数据，再由教练结合训练阶段、测试条件和现场表现解释，不把单次升降直接当成训练效果结论。

第三个问题，**这支队伍一段时间内的训练投入与节奏如何？** 这就需要训练课次数据，包含实际训练时长、分类以及有记录的RPE等。训练负荷中的SRPE依赖有效训练时长与RPE，两者不完整就不能凭空计算。

所以，今天刚导入的是测试成绩，训练时长、训练负荷和恢复图表不会因此自动补齐。不同数据承担不同用途：测试反映某次能力表现，课次记录反映做了什么训练，恢复记录帮助了解训练反应。

对领导汇报时，建议围绕四句话：本周记录了哪些训练和测试；从现有数据看到了什么；哪些地方还缺少依据；教练准备采取什么措施或需要什么支持。这样既有数据，也有业务判断。

### 第6段｜周总结：生成Word后继续修改（3分钟）

**屏幕操作：** 打开“数据管理 → 报告”，选择队伍和周次，点击“生成并下载Word”；打开文档。

**照着讲：**

日常数据持续记录后，周总结可以从这里生成。选择队伍和周次，核对对应的周一到周日范围，再点击“生成并下载Word”。训练阶段和教练补充是选填项，需要解释训练背景或说明下周安排时，可以补充。

报告会综合已有专项与体能数据，呈现训练概览、计划与执行、重点内容和运动员表现、恢复与风险管理、下周目标等内容，并保留相应图表和表格。

如果启用“允许AI”，系统会基于提供的统计信息起草文字。生成的分析和建议需要教练核对，不代表系统能自动知道所有训练背景，也不能替代教练做专业结论。

下载后可以用Word或WPS修改。当前项目不展示周总结正文，也没有队伍周总结的在线历史报告入口，需要保留的成品由大家自行保存。

缺少数据的图表仍会保留结构，数值为空。需要补充时，在支持图表编辑的Word/WPS版本里编辑图表数据，之后同时核对正文和相关表格，避免图改了、文字还是旧结论。

### 第7段｜收尾：会后先把一件小事做成（2分钟）

**屏幕操作：** 回到数据导入页，停留在模板和四步进度处。

**照着讲：**

今天大家先记住这条操作路线：选项目和队伍，下载合适模板，填写实际数据，上传检查，确认人员和数据，再查看入库结果。

建议会后先从每支队伍一次真实测试开始，不急着把全部历史文件一次性整理完。先用两三名运动员的小样本把流程走通，确认人员、日期和成绩都对，再处理同批其余数据。

教练重点负责确认数据的实际含义和训练解释；负责整理数据的同事可以协助填表和上传；领导和队伍负责人围绕已经确认的数据看投入、变化和需要支持的事项。具体由谁录入，可以按各队现有分工确定，不额外增加一套繁琐流程。

系统的价值需要靠持续、真实的记录积累。我们先把数据正确放进来，再让这些数据服务训练和汇报。

接下来可以现场提问，尤其是大家手里已有的Excel应该怎么选模板、怎么整理，我们可以拿具体情况说明。

## 四、现场常见问题与可直接使用的回答

| 可能的问题 | 建议回答 |
| --- | --- |
| 16列必须全部填满吗？ | 不需要。只填本次实际测到的项目；身份和日期核对好，未测试的指标真正留空。 |
| 只测了体重能导吗？ | 可以，只填写实际体重和有效测试日期，其余指标留空。 |
| 编号要自己编吗？ | 不要。已有人员用系统预填编号；新人编号留空，填写姓名与已有队伍，走人员确认。 |
| 队里有同名运动员怎么办？ | 先核对系统编号；出现歧义时人工选择已有人员，不能仅凭姓名猜。 |
| 新人必须先补生日、性别吗？ | 这次导入沿用最小建档确认，先确认姓名和队伍，其他资料可以后续补充。 |
| 这次没有参测的人要删掉吗？ | 不需要。只有身份、日期或备注，没有测量和测试数据的行会被忽略。 |
| 历史成绩能导吗？ | 可以，务必写实际测试日期，别保留下载时预填的当天日期。 |
| 一名运动员两次测试怎么填？ | 不同测试日期另起一行，编号一致。相同日期同项目的多次试次不要在这张简表里随意重复填写，先确认应采用的成绩，需保留试次时使用适用的测试模板。 |
| 日常深蹲训练重量填最大力量列吗？ | 不填。最大力量列只填实测1RM，训练组数、次数和日常重量走训练记录模板。 |
| 引体向上没做，能填0吗？ | 不能。没测留空；实际测了且有效次数确实为0，才填0。 |
| 坐位体前屈负数会报错吗？ | 在现有指标允许范围内可以填负数，例如-3。数值应来自实际测试。 |
| 上传成功就完了吗？ | 没有。先校对，再确认导入，最后看结果和业务页面。 |
| 导错了能直接再传一份吗？ | 先核对错误批次和影响记录。相同业务记录可能被更新，应明确本次更正范围并查看最终更新内容；如果日期或人员本身填错，重传正确数据不等于自动删除错误记录。 |
| 重复上传会怎样？ | 同一文件可继续已有批次或按页面重新解析；已入库记录沿用既有去重和更新规则。先看批次状态及新增、更新内容，不要假定重传永远无影响。 |
| 老模板还能用吗？ | 历史合法模板保留兼容。新录入的常见基础体能成绩，优先使用当前下载的单表模板。 |
| 为什么导入成功，图表还是空的？ | 先检查项目、队伍、日期和指标，再确认该图需要哪类数据。导入体测成绩不会补出日常训练和恢复数据；只有一次测试也没有连续趋势。 |
| 系统能自动判断运动员伤病或给出训练结论吗？ | 可以辅助呈现已记录的训练和状态信息，最终判断仍要结合专业评估和教练现场情况，不能仅凭一个指标下结论。 |
| 周总结可以修改吗？ | 可以，下载Word后自行修改；修改图表时同步核对相关正文和数字。 |

## 五、现场演示出现问题时，怎样继续讲

### 下载或上传较慢

“现场正在处理，我先用事先准备好的同版本文件说明填写方式，再展示已经完成的导入结果。实际操作的顺序没有变化。”

随后打开准备好的文件或批次；不要反复点击提交，也不要说尚未成功的操作已经完成。

### 出现日期、数值错误

“这里正好说明系统为什么先检查、再入库。它指出这条数据需要修正，我们先核对原表和单元格，修正后再确认。”

只处理一条清楚的错误作为演示，其他异常留到会后，不让会议变成逐行修表。

### 看不到某个菜单、队伍或运动员

“不同账号可见范围不同。我们先确认当前账号、项目和授权队伍，再使用已准备好的演示范围继续。”

不要现场修改权限去凑演示结果，也不要把无权限误讲成系统没有数据。

### 周总结现场生成较慢

“报告生成需要处理数据和图表，我先打开已经生成的示例说明最终效果。实际使用仍然是选择队伍、周次后生成并下载。”

## 六、讲解者最后放在手边的一页提词卡

**开场：** 今天重点学会把数据正确导入，再看怎么用。

**价值：** 按运动员、队伍和时间积累记录，一份数据用于查看、分析和总结。

**先选范围：** 项目 → 队伍 → 日期。

**选模板：** 基础体能用统一单表；名单资料、日常训练、其他测试分别用对应模板。

**填表六句话：**

1. 已有编号不改，新人编号留空。
2. 日期用实际测试日期。
3. 单位看表头，单元格只填数字。
4. 最大力量只填实测1RM。
5. 未测留空，真实0保留。
6. 同一个人不同日期另起一行。

**导入六步：** 下载 → 填写 → 上传检查 → 确认人员 → 校对入库 → 查看结果。

**确认前看四点：** 人、日期、数值及单位、新增还是更新。

**结果提醒：** 一行可拆成多条业务记录；上传不等于入库；重传正确文件不会自动删除原来填错身份或日期的记录。

**看数据：** 测试看能力表现，课次看投入与节奏，恢复看训练反应；不同来源不能互相代替。

**周总结：** 数据管理 → 报告 → 队伍/周次 → 生成并下载Word → 教练核对修改。

**收尾：** 每队先用一次真实测试的小样本走通流程，再持续积累。
